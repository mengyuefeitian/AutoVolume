为网络卷保活

AutoVolume 专注做一件事：让 macOS 的网络文件服务器挂载更稳定、更少打扰、更容易恢复。

多协议支持

支持 SMB、WebDAV、AFP、NFS，可为每个卷独立配置服务器、路径、账号和挂载点。

断网恢复

网络恢复后自动重新连接，处理占用的旧挂载点，减少 Finder 中假在线的问题。

目录直达

支持挂载服务器内部目录，例如 SMB 的 share/folder；WebDAV 会解析真实挂载点，只打开最终目标窗口。

本地加密

密码保存在本地加密文件中，不依赖钥匙串，错误输出会自动脱敏。

SMB2-SMB3

默认支持 SMB2 到 SMB3 自动协商，不启用 SMB1，并可配置 SMB3 Multichannel。

手动控制

列表内支持挂载、卸载、编辑和移除。手动卸载只是临时操作，启用状态下仍会按检查间隔保活。

适合长期挂载 NAS 和私有云

AutoVolume 更像一个安静的菜单栏守护工具，不抢屏幕、不频繁弹系统窗口，只在需要时把网络卷恢复到可用状态。

  • WebDAV 体验优化
    兼容 HTTPS WebDAV，挂载后会清理重复 Finder 窗口，并进入系统真实挂载目录。
  • 网络恢复后重连
    网络短暂中断时按 1 分钟节奏检测恢复；其他错误按配置的检查间隔处理。
  • 减少钥匙串打扰
    凭据使用本地加密文件保存，避免 macOS 钥匙串反复请求授权。

安装和使用

打开 DMG，将 AutoVolume 拖入 Applications。
从 Applications 启动，允许 macOS 网络卷宗权限。
添加服务器地址、远程路径、账号和检查间隔。
挂载成功后，AutoVolume 会保持检测并在需要时重连。
